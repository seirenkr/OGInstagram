## Server and image runtime

- [`modernc.org/sqlite`](https://pkg.go.dev/modernc.org/sqlite) uses BSD-3-Clause; its generated SQLite source is derived from [SQLite, in the public domain](https://www.sqlite.org/copyright.html). Go module dependencies retain their own license files in the module distribution.
- [`golang.org/x/image`](https://pkg.go.dev/golang.org/x/image) uses BSD-3-Clause, copyright the Go Authors, including the WebP decoder used by media previews.
- The production image installs Debian's [`ffmpeg`](https://packages.debian.org/bookworm/ffmpeg). FFmpeg licensing depends on enabled components; the Debian binary includes GPL components. Its package copyright and license text remain in `/usr/share/doc/ffmpeg/copyright` in the image. See [FFmpeg's license information](https://ffmpeg.org/legal.html) and the corresponding [Debian source package](https://packages.debian.org/source/bookworm/ffmpeg).
- The image retains the existing pinned [`h4ckf0r0day/obscura`](https://hub.docker.com/r/h4ckf0r0day/obscura) runtime and [`playwright-core`](https://github.com/microsoft/playwright/blob/main/LICENSE) (Apache-2.0) for external-helper key harvesting.
